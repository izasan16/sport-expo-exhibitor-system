# 技术架构图 AI 生图提示词

## 推荐提示词

```text
请生成一张“中国国际体育用品博览会展商业务系统”技术架构图，横向 16:9，建议 1920×1080。

整体采用简洁、克制、专业的企业软件文档风格。白色背景，深蓝色标题和文字，浅蓝色分区，少量绿色和橙色作为层级区分。使用统一的圆角卡片、细灰色边框、轻微阴影，不使用复杂渐变、霓虹色、3D 特效或装饰性背景。

顶部标题：
“中国国际体育用品博览会展商业务系统”
副标题：“技术架构图”

画面分为四个水平层级，每层使用一个浅色横向容器，左侧显示层级名称和简洁图标，右侧排列整齐的独立模块卡片。层级之间只通过上下布局、颜色和留白表达关系，不绘制连接线、箭头或数据流。

第一层：访问端
浏览器、移动端浏览器、管理员端、展商端。

第二层：前端应用
React、TypeScript、Vite、Ant Design、React Router、场景编辑器、管理工作台、展商工作台。

第三层：后端服务
Spring Boot 3、Java 17、认证与 JWT、RBAC 权限服务、展商服务、订单服务、合同与付款服务、展位服务、场景服务、CAD 转换任务、文件上传服务、审计日志。

第四层：数据与基础设施
PostgreSQL、Redis、持久化文件存储、DWG/DXF 文件、SVG 场景文件、Docker Compose、Render 部署。

模块卡片大小统一，间距均匀，文字简短清晰，图标使用简单的线性或扁平化图标。整体布局参考成熟企业软件技术白皮书和 GitHub 项目 README 架构图，信息清楚，视觉安静，不要做成宣传海报或复杂网络拓扑图。
```

## 负面提示词

```text
不要连线，不要箭头，不要流程线，不要数据流线，不要网络拓扑，不要 UML 图，不要时序图，不要复杂渐变，不要霓虹色，不要赛博朋克，不要 3D 机房，不要装饰性粒子，不要人物照片，不要大量立体图标，不要密集小字，不要乱码，不要水印，不要模块重叠，不要卡片倾斜，不要透视变形，不要花哨背景。
```

## 版式约束

- 四个层级必须完整保留：访问端、前端应用、后端服务、数据与基础设施。
- 每层使用横向分区，模块卡片水平排列并保持统一尺寸。
- 不使用连接线表达架构关系，只使用层级、区域、对齐和留白表达结构。
- 标题和层级名称使用深蓝色，前端层可使用浅蓝色，后端层可使用浅绿色，数据层可使用浅橙色。
- 如果模型生成的中文文字不准确，先保留卡片与图标布局，再在 Figma、PPT 或 SVG 中替换文字。
